# group-o-mat.de

Statische Website für die iOS-App Group-O-Mat: Startseite, Support, Datenschutzerklärung (de/en), Impressum. Kein JavaScript, keine Cookies, keine Drittinhalte.

Gehostet über GitHub Pages mit eigener Domain (`CNAME`). Änderungen: HTML-Dateien bearbeiten, pushen. Die Datenschutzerklärung wird aus `Docs/Datenschutz.md` des App-Repositorys übernommen.

Offen: Name und Anschrift in `impressum.html`, `datenschutz.html` und `privacy.html` eintragen (Platzhalter in eckigen Klammern).
